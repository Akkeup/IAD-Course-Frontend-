# M31 Galaxy Andromeda — лабораторная №5

Гостевое SPA на **React + TypeScript + Vite**, компоненты **React-Bootstrap**.
Карточки читаются из локальной mock-коллекции. Backend, PostgreSQL, Redis и
MinIO для запуска не нужны. Redux и Context в коде приложения не используются.

## Запуск

Нужны Node.js 22.12+ и npm.

```sh
npm ci
npm run dev
```

Открыть URL из терминала: по умолчанию `http://127.0.0.1:5173`.
Если порт занят, Vite выберет следующий свободный.

```sh
npm run build    # проверка TypeScript и production-сборка в dist/
npm run preview  # просмотр production-сборки
npm test         # четыре DOM-теста поведения приложения
```

После установки зависимостей приложение не обращается к внешним API, CDN,
шрифтам или интернет-медиа. Результат сборки можно обслуживать статическим сервером.

## Три страницы, кнопки и поля

### Лента — `#/feed`

Фоновое изображение звезды, заголовок M31 / Galaxy Andromeda, название,
каталожный ID, краткое описание, число отметок, расстояние от центра галактики
и скорость. «Дальше» переключает на следующую звезду; после последней идёт
первая. «ещё» / «свернуть» раскрывает описание. Нажатие на название открывает
подробную карточку. Сердце показывает число отметок и не изменяет mock-данные.

### Плитка — `#/catalog`

Стартовая страница «Звёзды M31»: шесть опубликованных объектов.
Карточка содержит изображение, название, расстояние и число отметок;
нажатие на карточку открывает объект.

Поле **«Максимальное расстояние от центра в килопарсеках»** — ползунок
от 0 до 35 с шагом 0.1. Справа отображается выбранное значение.
**«Найти»** применяет ограничение `distance_kpc <= выбранное значение`.
Перемещение ползунка само по себе результат не меняет.
**«Сбросить»** снимает фильтр и возвращает ползунок к 35 кпк.
Если результатов нет, появляется сообщение и кнопка **«Показать все»**.
При возврате из карточки применённый фильтр сохраняется до перезагрузки.

### Подробная карточка — `#/stars/:id`

Например, `#/stars/1`. Изображение, название, каталожный ID, расстояние,
скорость, описание, статус, число отметок и видео с элементами управления.
Ссылка **«К звёздному каталогу»** возвращает в плитку.
При неизвестном ID показывается «Звезда не найдена» и ссылка на каталог.

### Нижняя navbar

**Лента**, **Добавление**, **Плитка**, **Вход**.
Доступны только «Лента» и «Плитка». Остальные отключены через React-Bootstrap
`disabled` / `aria-disabled`. Активная страница выделена голубым.
SPA поддерживает hash-ссылки и историю браузера без загрузки нового документа.

## Mock и локальные медиа

`src/data/stars.ts` содержит шесть объектов из опубликованной выборки
`migrations/0002_seed_andromeda.sql` исходного проекта: те же названия,
каталожные ID, описания, расстояния, скорости и начальные числа отметок.
`src/types.ts` описывает поля `ApiStar`. Черновики и удалённые объекты гостю
не показываются. Данные импортируются напрямую, без `fetch` и Axios.

Настоящие `images/*.webp` и `videos/*.mp4` в исходном backend находятся в
MinIO и **не включены в GitHub-репозиторий**. Для автономного mock перенесены
оригинальные файлы по умолчанию из `static/defaults`:

- `public/media/default-star.svg`;
- `public/media/default-star.mp4`.

Оба файла побайтово совпадают с исходными. В mock-коллекции обычные карточки
ссылаются на эти локальные медиа. У **M31-2252** (`#/stars/4`) специально
оставлены `image_url: ''` и `video_url: ''`, чтобы продемонстрировать
автоматическую подстановку при пустых полях услуги.

`src/components/StarMedia.tsx`: `StarImage` и `StarVideo` выбирают локальный
файл при пустом URL и при ошибке загрузки. На подробной странице есть подписи
к медиа по умолчанию. Состояние ошибки сбрасывается при смене объекта через
`key`. Если сам fallback недоступен, бесконечной подстановки не возникает.

Во вкладке Network будут HTML, JS, CSS, SVG и MP4 с localhost. REST API
не вызывается. В режиме разработки также будет WebSocket Vite для HMR.
Для показа видео нажмите Play; скачивание локального MP4 не является запросом к backend.

## Компоненты и props

- `App` хранит применённый фильтр и выбирает страницу по hash-маршруту.
- `CatalogPage` получает `filters`, `onChange`; вызывает `filterStars`.
- `StarFilters` получает `value`, `onChange`, `onReset`. Локально хранит
  черновое значение ползунка и по кнопке передаёт новый фильтр родителю.
- `StarCard` получает объект `star`.
- `StarImage` получает `src`, `name`, необязательные `className` и
  `showFallbackLabel`; `StarVideo` получает `src`.
- `StarPage` получает числовой `id`; `BottomNav` получает текущий `route`.
- `FeedPage` хранит индекс выбранной звезды.

React-Bootstrap: `Navbar`, `Nav.Link`, `Card`, `Form`, `Form.Label`,
`Form.Range`, `Button`. Bootstrap CSS установлен локально.
Внешний роутер не подключён; маршрутизацию выполняет `useHashRoute`.

## Все используемые хуки

**`useState`:** `App.tsx` — применённый фильтр; `StarFilters.tsx` — положение
ползунка; `FeedPage.tsx` — индекс звезды; `StarMedia.tsx` — отдельные состояния
ошибки изображения и видео; `useHashRoute.ts` — текущий маршрут.

**`useEffect`:**

- `useHashRoute.ts`, зависимости `[]`: подписка на `hashchange`, изменение
  маршрута и прокрутка наверх. Cleanup удаляет обработчик при размонтировании.
- `App.tsx`, зависимости `[route]`: обновление `document.title`.

**`useHashRoute`** — собственный хук на основе `useState` и `useEffect`.
Других хуков в коде приложения нет. Раскрытие описания использует нативный
checkbox и CSS, как в исходном шаблоне. Включён `StrictMode`.
